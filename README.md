# 🇪🇺 Viaje Familiar 2026 · España e Italia

Web de una sola página para organizar un viaje familiar de **Buenos Aires a Europa**, del **23 de marzo al 15 de abril de 2026** (24 días), para **4 pasajeros**.

## 🗺️ Ruta

Buenos Aires ✈️ **Mallorca** → **Barcelona** → **Madrid** → **Italia** (Roma · Florencia · Venecia) ✈️ Buenos Aires

## ✨ Contenido de la web

La página (`index.html`) tiene 5 secciones con un menú fijo arriba:

- 🏠 **Resumen** — ruta, fechas, pasajeros y distribución de los 24 días.
- 📆 **Itinerario** — plan día a día de todos los destinos.
- 💰 **Presupuesto** — estimación austera en **€ y ARS**, con tipo de cambio editable que recalcula todo.
- 🧳 **Equipaje** — checklist marcable que se guarda en el navegador.
- 📝 **Notas** — bloc para vuelos y reservas, con guardado automático.

## 🚀 Cómo verla

Abrí `index.html` en cualquier navegador (también funciona bien en el móvil). No requiere instalar nada.

## 📁 Archivos

| Archivo | Descripción |
|---------|-------------|
| `index.html` | La página web |
| `styles.css` | Estilos y diseño responsive |
| `script.js` | Presupuesto, checklist y notas interactivas |
